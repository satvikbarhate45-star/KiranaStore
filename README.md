# स्मार्ट किराणा एंटरप्राइज (Smart Kirana Enterprise) v1.1

> **पारदर्शक भाव, बिनचूक हिशोब आणि सुरक्षित व्यवहार — आपल्या हक्काचे डिजिटल किराणा व्यासपीठ.**

**Smart Kirana Enterprise** हे स्थानिक किराणा (नेबरहुड किराणा) खरेदीसाठी तयार केलेले उत्पादन-दर्जाचे (Production-Grade) वेब प्लॅटफॉर्म आहे. हे व्यासपीठ घरगुती किराणा यादीचे **Gemini AI शुद्धीकरण**, दुकानदाराचे **रिव्हर्स बिलिंग काउंटर (Reverse POS)**, मागील ५ फेऱ्यांच्या दरांचे **रोलिंग मीडियन बजेट ऑडिट (Rolling Median Audit)** आणि सुरक्षित **शून्य-कीईंग UPI QR पेमेंट** एकात्मिकरीत्या उपलब्ध करते.

---

## 🌟 प्रमुख वैशिष्ट्ये (Core Features)

1. **AI यादी शुद्धीकरण व नॉर्मलायझेशन (Gemini 2.5 Flash API + Local Regex Fallback):**
   - ग्राहकांनी घाईघाईत टाईप केलेल्या अशुद्ध किंवा जोडलेल्या शब्दांचे (उदा. `साखर२किलो`, `shengdanatel2L`, `तुरीची डाल 1kg`, `तांदूळ 500 gm`) शुद्ध मराठी कॅटलॉग नामात रूपांतर.
   - रोमानिकृत इंग्रजी (Manglish) अक्षरांचे शुद्ध देवनागरीमध्ये रूपांतर.
   - ग्राम (`gm`) ते किलोग्रॅम (`kg`) आणि मिलिलीटर (`ml`) ते लिटर (`L`) स्वयंचलित रूपांतर.
   - **Deterministic Validators (V1 ते V7):** AI कडून येणाऱ्या कोणत्याही चुकीच्या किंवा फँटम उत्पादनांना त्वरित रोखले जाते.
   - **Graceful Fallback:** इंटरनेट खंडित झाल्यास किंवा AI उपलब्ध नसल्यास स्थानिक रेगुलर एक्स्प्रेशन पार्सरवर आपोआप स्विच होते (`स्मार्ट सुधारणा उपलब्ध नाही, साधा पार्सर वापरला आहे.`).

2. **दुकानदार रिव्हर्स बिलिंग काउंटर (Reverse POS Engine):**
   - दुकानदाराला प्रति युनिट दर विचारण्याची गरज नाही; तो काउंटरवर केवळ प्रत्येक वस्तूची **एकूण रक्कम (₹)** नोंदवतो.
   - सिस्टीम तत्काळ प्रत्येक इनपुट इव्हेंटवर `<20 ms` मध्ये आजचा खरा युनिट दर `(एकूण रक्कम ÷ प्रमाण)` काढते.
   - गणितीय चुका किंवा तोंडी दरांमधील विसंगती कायमच्या दूर होतात.

3. **ऐतिहासिक भाववाढ व बजेट ऑडिट (Rolling Median Volatility Engine):**
   - प्रत्येक वस्तूचा आजचा दर ग्राहकाच्या गेल्या ५ खरेदींच्या मध्यक दराशी (Rolling Median) पडताळला जातो.
   - **रिअल-टाइम स्टेटस बॅजेस:**
     * `संतुलित`: दर फरक \|Variance\| ≤ ५%
     * `भाववाढ`: दर वाढ > +६%
     * `स्वस्त`: दर कपात < -२%
     * `नवीन नोंद`: प्रथमच खरेदी केलेली वस्तू (नवीन बेसलाईन)
   - **बास्केट-पातळी ऑडिट:** संपूर्ण किराणा खरेदीचे बजेट समतोल (`संतुलित बजेट` vs `असंतुलित खर्च`) त्वरित दाखवले जाते.

4. **हार्डवेअर WebRTC QR स्कॅनर व शून्य-कीईंग UPI पेमेंट:**
   - थेट मोबाईल कॅमेरा किंवा वेबकॅमद्वारे दुकानदाराचा PhonePe, Google Pay किंवा Paytm UPI QR कोड स्कॅन केला जातो.
   - सिस्टीममधील अचूक एकूण देय रक्कम (Grand Total) आपोआप `upi://pay?pa=...&am=...&cu=INR` लिंकमध्ये भरली जाते.
   - ग्राहकाला रक्कम हाताने टाईप करावी लागत नाही; चुकीची किंवा अतिरिक्त रक्कम भरण्याचा धोका शून्य!
   - **शून्य कॅमेरा फ्रेम साठवणूक:** कॅमेरा डेटा सर्व्हरवर कधीही सेव्ह होत नाही; सर्व प्रक्रिया स्थानिक डिव्हाइसवर होते.

## 🗺️ बहु-पृष्ठीय आर्किटेक्चर (Multi-Page Architecture)

| पृष्ठ (Page) | इंग्रजी रूट | मुख्य कार्ये |
|---|---|---|
| **मुख्यपृष्ठ** | `/` (`index.html`) | बॅच यादी सबमिशन, Gemini AI शुद्धीकरण, रिव्हर्स बिलिंग काउंटर, रिअल-टाइम बॅजेस, WebRTC QR स्कॅनर, डेटाबेस सेव्ह. |
| **खरेदी इतिहास** | `/history/` (`history.html`) | मागील सर्व पावत्या, तारीख/दुकानदार/स्थितीनुसार फिल्टर्स, वस्तूंचा सविस्तर तपशील (Modal Drill-down), पावती प्रिंट/डाउनलोड, आणि कायमचे हटवणे (Deletion). |
| **दर विश्लेषक व सिम्युलेटर** | `/analyzer/` (`analyzer.html`) | बजेट सिम्युलेटर (बाजारात जाण्यापूर्वी खर्च अंदाज), दोन खरेदींची समोरासमोर तुलना (Trip Comparator), आणि ३०/६०/९० दिवसांचा भाववाढ व स्वस्त वस्तूंचा परस्परसंवादी आलेख. |
| **आमच्याबद्दल** | `/about/` (`about.html`) | सिस्टीमचे ४ मूलभूत आधारस्तंभ, तांत्रिक कार्यप्रणाली, पारंपरिक खरेदीशी तुलना, आणि DPDP कायदा २०२३ सुरक्षा मानके. |
| **संपर्क व सहाय्य** | `/contact/` (`contact.html`) | ग्राहक व दुकानदार चौकशी फॉर्म, तक्रार निवारण तिकीट निर्मिती (Ticket ID), आणि टोल-फ्री हेल्पलाइन. |
| **पावती प्रिंट** | `/receipt/{trip_id}` (`receipt.html`) | थर्मल व A4 प्रिंटरसाठी सुसंगत औपचारिक मराठी खरेदी पावती. |

## 🛠️ तंत्रज्ञान स्टॅक (Technology Stack)

- **बॅकएंड:** Python 3.11+, FastAPI (हाय-परफॉर्मन्स Asynchronous REST API), Pydantic v2.
- **डेटाबेस:** PostgreSQL 15+ (किंवा तत्काळ रन करण्यासाठी SQLite WAL मोड). SQLAlchemy 2.0 ORM.
- **AI इंजिन:** Google GenAI SDK (`google-genai`), `gemini-2.5-flash` (कॉन्फिगरेशन-ड्रिव्हन मॉडेल).
- **फ्रंटएंड:** सिमेंटिक HTML5, Vanilla CSS3 (मुक्ता व नोटो सॅन्स देवनागरी फॉन्ट, भारतीय फिनटेक सफ्रॉन थीम, ग्लासमोर्फिझम), Vanilla ES2020 JavaScript.
- **कॅमेरा व QR:** WebRTC `MediaDevices`, `BarcodeDetector` API आणि फॉलबॅक डिकोडर.

## 🚀 स्थानिक पातळीवर चालवणे (Quickstart Guide)

### १. प्रकल्प क्लोन किंवा डिरेक्टरी उघडा
```powershell
cd c:\projects\KiranaStore
```

### २. डिपेंडन्सीज इन्स्टॉल करा
```powershell
pip install -r requirements.txt
```

### ३. वातावरण कॉन्फिगरेशन (.env)
प्रकल्पात `.env` फाईल आधीच उपलब्ध आहे. आपण हवी असल्यास स्वतःची Gemini API की टाकू शकता:
```env
GEMINI_MODEL=gemini-2.5-flash
GEMINI_API_KEY=your_gemini_api_key_here
PORT=8000
HOST=127.0.0.1
```
*(टीप: जर `GEMINI_API_KEY` रिकामी असेल, तरीही सिस्टीम स्वयंचलितरीत्या स्थानिक रेगुलर एक्स्प्रेशन पार्सरवर अखंडपणे चालते.)*

### ४. स्वयंचलित युनिट व इंटिग्रेशन चाचण्या चालवा
```powershell
python -m unittest discover tests
```

### ५. सर्व्हर सुरू करा
```powershell
python run.py
```
किंवा थेट Uvicorn द्वारे:
```powershell
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

आता आपल्या ब्राउझरमध्ये उघडा:
👉 **http://127.0.0.1:8000/**

## 📡 मुख्य API एंडपॉइंट्स (API Endpoints)

| पद्धत | एंडपॉइंट | वर्णन |
|---|---|---|
| `POST` | `/api/v1/lists/parse` | कच्च्या किराणा यादीचे AI शुद्धीकरण व प्रमाणीकरण |
| `GET` | `/api/v1/baselines` | वस्तूंच्या मागील ५ खरेदींचे रोलिंग मध्यक दर |
| `POST` | `/api/v1/trips` | पूर्ण झालेली खरेदी डेटाबेसमध्ये जतन करणे (Session ID Idempotency) |
| `GET` | `/api/v1/trips` | मागील खरेदी नोंदींची यादी (फिल्टर्ससह) |
| `GET` | `/api/v1/trips/{id}` | खरेदीचा संपूर्ण वस्तूवार तपशील |
| `DELETE` | `/api/v1/trips/{id}` | खरेदी नोंद हटवणे व बेसलाईन अद्ययावत करणे |
| `POST` | `/api/v1/analyzer/simulate` | नियोजित खरेदी खर्चाचा अंदाज काढणे |
| `GET` | `/api/v1/analyzer/trends` | ३०/६०/९० दिवसांचा भाववाढ व स्वस्त दर अहवाल |
| `GET` | `/api/v1/analyzer/compare-trips` | दोन खरेदींची समोरासमोर तुलना |
| `POST` | `/api/v1/contact` | मदत व चौकशी तक्रार नोंदवणे (तिकीट निर्मिती) |
| `GET` | `/api/v1/health` | सिस्टीम व AI आरोग्य तपासणी |

## 🔒 ग्राहक व व्यापारी गोपनीयता (Security & Compliance)
- **शून्य कॅमेरा फ्रेम साठवणूक:** QR कोड थेट ग्राहकाच्या स्थानिक ब्राउझरमध्ये डिकोड होतो. कॅमेरा इमेजेस सर्व्हरवर पाठवल्या किंवा सेव्ह केल्या जात नाहीत.
- **डेटा मिनिमायझेशन:** AI कडे केवळ किराणा वस्तूंचे नाव व प्रमाण जाते; ग्राहकाचा फोन नंबर, नाव किंवा आर्थिक तपशील कधीही पाठवले जात नाहीत.
- **DPDP Act 2023:** संपूर्ण प्रणाली भारतीय डिजिटल व्यक्तिगत डेटा संरक्षण (DPDP) कायदा २०२३ च्या मार्गदर्शक तत्त्वांचे पालन करते.
